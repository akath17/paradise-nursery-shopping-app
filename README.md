# Paradise Nursery Shopping Application

Paradise Nursery is a React and Redux shopping-cart application for an online plant shop.

## Features

- Landing page with company information and a Get Started button
- Houseplants arranged into multiple categories
- Plant images, descriptions, and prices
- Add to Cart buttons with disabled states after selection
- Dynamic shopping-cart item count
- Increase and decrease item quantities
- Remove items from the cart
- Individual plant totals and complete cart total
- Continue Shopping and Checkout buttons

## Technologies Used

- React
- JavaScript
- Redux Toolkit
- HTML
- CSS
- Vite
